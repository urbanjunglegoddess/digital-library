# Skeleton

# The Skeleton: A Senior Engineer's Complete Breakdown
The structural placeholder that makes loading feel intentional instead of broken. Here's everything from first principles to production code.

**Try it live:** the interactive playground (built in a later pass) will let you configure shape, animation, and layout variants.

This doc follows the Private ([https://app.clickup.com/8495850/docs/838qa-81211/838qa-200531](https://app.clickup.com/8495850/docs/838qa-81211/838qa-200531)) and its visual styles are drawn from the Private ([https://app.clickup.com/8495850/docs/838qa-87871/838qa-200551](https://app.clickup.com/8495850/docs/838qa-87871/838qa-200551)).

* * *
## 1\. What a Skeleton Actually Is
A **skeleton screen** (content placeholder, shimmer) is a set of low-fidelity shapes that mirror the layout of the content that's about to appear. It's not a spinner saying "wait" — it's a preview saying "here's what's coming."

**Skeleton (this doc):** structural placeholder matching the content's shape. Reduces perceived load time by showing the page structure immediately.
**Spinner:** says "loading" with no structural information.
**Progress Bar:** says "X% done."

Facebook popularized skeletons in 2014. The research is clear: skeleton screens reduce _perceived_ wait time by up to 35% compared to spinners, because the brain processes them as partial content rather than an empty state.

* * *
## 2\. Why It Matters
**Perceived performance.** The user sees structure immediately. The page feels faster even when it isn't.
**Layout stability.** Skeletons reserve space, preventing Cumulative Layout Shift (CLS) when content loads. Good for Core Web Vitals.
**Cognitive priming.** The skeleton tells users what kind of content to expect, reducing cognitive load when the real content appears.

* * *
## 3\. Anatomy
**Text lines:** horizontal rectangles at ~60-80% width, varying lengths to mimic natural text.
**Circles:** avatar or image placeholders.
**Rectangles:** card images, video thumbnails, banners.
**Rounded rects:** button or chip placeholders.
**Animation:** a shimmer (moving highlight gradient) or pulse (opacity oscillation) that signals "loading" without being as interruptive as a spinner.
**Container:** mirrors the exact dimensions and spacing of the real component.

* * *
## 4\. Sizes / Scale
Skeletons don't have their own size scale — they inherit the dimensions of whatever they're replacing:

| Target | Skeleton Shape | Dimensions |
| ---| ---| --- |
| Heading | Rounded rect | 60% container width × 24-32px H |
| Body text | Rounded rect × 3-4 lines | 100%/90%/75% width × 14-16px H, 8px gap |
| Avatar | Circle | Match avatar size (24-80px) |
| Card image | Rounded rect | Match image aspect ratio |
| Button | Rounded rect | Match button dimensions |
| Input field | Rounded rect | Match field height × full width |

The rule: **match the real component's box model exactly** so there's zero layout shift when content replaces skeleton.

* * *
## 5\. States
**Animating:** the default. Shimmer or pulse is running.
**Static (reduced motion):** under `prefers-reduced-motion`, the skeleton is visible but doesn't animate. Still clearly a placeholder via its flat gray color.
**Transitioning out:** when content arrives, the skeleton fades/dissolves and real content fades in. A smooth crossfade prevents flicker.
**Hidden:** unmounted after content loads.

* * *
## 6\. Types / Variants
**Shimmer:** a diagonal gradient highlight sweeps across the skeleton (the most common).
**Pulse:** the skeleton's opacity oscillates (simpler, cheaper).
**Wave:** the shimmer moves in a wave pattern across multiple elements.
**Static:** no animation (used when reduced-motion is on or when inside a container that already has a spinner).

Composition variants:
**Card skeleton:** image rect + heading line + body lines + button rect.
**List skeleton:** repeating rows of avatar circle + text lines.
**Table skeleton:** grid of rectangles matching column widths.
**Form skeleton:** stacked label lines + field rects.

* * *
## 7\. When to Use (and When Not To)
**Use skeletons when:**
*   Content layout is predictable (you know what's coming)
*   Load time is 1-5 seconds
*   Multiple content items load (lists, grids, feeds)
*   You want to minimize CLS

**Use something else when:**
*   You don't know the content shape → Spinner
*   The action is instantaneous (< 200ms) → Show nothing
*   A single small element is loading → Inline spinner
*   The wait exceeds 10s → Add a progress indicator on top of the skeleton
*   Content might not exist (search results) → Don't show 10 skeleton cards for a search that returns 0

* * *
## 8\. Across Design Systems
**Material:** doesn't ship a dedicated skeleton component; relies on staggered content appearance. Community libraries fill the gap.
**Ant Design:** `<Skeleton>` with `active` (shimmer), `avatar`, `title`, `paragraph` shape props.
**Chakra:** `<Skeleton>`, `<SkeletonText>`, `<SkeletonCircle>`. `isLoaded` prop crossfades to real content.
**MUI:** `<Skeleton variant="text|circular|rectangular|rounded">` with animation="wave|pulse".
**shadcn:** `<Skeleton>` utility component (a styled div with pulse animation).

### 9.2 React + TypeScript

```typescript
interface SkeletonProps {
  variant?: "text" | "rect" | "circle";
  width?: string | number;
  height?: string | number;
  lines?: number;
  animate?: "shimmer" | "pulse" | "none";
}

export function Skeleton({ variant = "text", width, height, lines = 1, animate = "shimmer" }: SkeletonProps) {
  if (variant === "text" && lines > 1) {
    return (
      <div aria-hidden="true">
        {Array.from({ length: lines }, (_, i) => (
          <div key={i} className={`skeleton skeleton--text skeleton--${animate}`}
               style={{ width: i === lines - 1 ? "75%" : "100%" }} />
        ))}
      </div>
    );
  }
  return (
    <div aria-hidden="true" className={`skeleton skeleton--${variant} skeleton--${animate}`}
         style={{ width, height }} />
  );
}
```

### 9.11 Web Components

```typescript
class UiSkeleton extends HTMLElement {
  static observedAttributes = ['variant', 'width', 'height', 'animate', 'lines'];

  connectedCallback() { this.attachShadow({ mode: 'open' }); this.render(); }
  attributeChangedCallback() { if (this.shadowRoot) this.render(); }

  render() {
    const variant = this.getAttribute('variant') || 'text';
    const width = this.getAttribute('width') || '100%';
    const height = this.getAttribute('height') || (variant === 'text' ? '14px' : '100px');
    const animate = this.getAttribute('animate') || 'shimmer';
    const lines = parseInt(this.getAttribute('lines') || '1');

    const shapeStyle = `width:${width};height:${height};`;
    const radiusClass = variant === 'circle' ? 'border-radius:50%;' : variant === 'rect' ? 'border-radius:8px;' : 'border-radius:4px;';

    let shapes = '';
    if (variant === 'text' && lines > 1) {
      shapes = Array.from({ length: lines }, (_, i) =>
        `<div class="skel ${animate}" style="width:${i === lines - 1 ? '75%' : '100%'};height:14px;margin-bottom:8px;border-radius:4px;"></div>`
      ).join('');
    } else {
      shapes = `<div class="skel ${animate}" style="${shapeStyle}${radiusClass}"></div>`;
    }

    this.shadowRoot!.innerHTML = `
      <style>
        :host { display: block; }
        .skel { background: var(--skeleton-base, #2a2a2e); position: relative; overflow: hidden; }
        .shimmer::after {
          content: ''; position: absolute; inset: 0;
          background: linear-gradient(90deg, transparent, rgba(255,255,255,0.04), transparent);
          animation: shimmer 1.5s infinite;
        }
        .pulse { animation: pulse 1.8s ease-in-out infinite; }
        @keyframes shimmer { from { transform: translateX(-100%); } to { transform: translateX(100%); } }
        @keyframes pulse { 0%,100% { opacity: 1; } 50% { opacity: 0.5; } }
        @media (prefers-reduced-motion: reduce) { .shimmer::after, .pulse { animation: none; } }
      </style>
      <div aria-hidden="true">${shapes}</div>`;
  }
}
customElements.define('ui-skeleton', UiSkeleton);
// <ui-skeleton variant="rect" height="180px" animate="shimmer"></ui-skeleton>
// <ui-skeleton variant="text" lines="3"></ui-skeleton>
// <ui-skeleton variant="circle" width="48px" height="48px"></ui-skeleton>
```

### 9.13 SwiftUI

```swift
import SwiftUI

struct SkeletonView: View {
    enum Variant { case text, rect, circle }
    enum Animation { case shimmer, pulse, none }

    var variant: Variant = .text
    var width: CGFloat? = nil
    var height: CGFloat = 14
    var animate: Animation = .shimmer

    @State private var isAnimating = false

    var body: some View {
        let shape = shapeView
            .foregroundColor(Color.gray.opacity(0.2))

        switch animate {
        case .shimmer:
            shape.overlay(shimmerOverlay).clipped()
        case .pulse:
            shape.opacity(isAnimating ? 0.5 : 1.0)
                .animation(.easeInOut(duration: 0.9).repeatForever(), value: isAnimating)
                .onAppear { isAnimating = true }
        case .none:
            shape
        }
    }

    @ViewBuilder
    private var shapeView: some View {
        switch variant {
        case .text:
            RoundedRectangle(cornerRadius: 4)
                .frame(width: width, height: height)
        case .rect:
            RoundedRectangle(cornerRadius: 8)
                .frame(width: width, height: height)
        case .circle:
            Circle()
                .frame(width: width ?? height, height: height)
        }
    }

    private var shimmerOverlay: some View {
        GeometryReader { geo in
            LinearGradient(
                colors: [.clear, .white.opacity(0.08), .clear],
                startPoint: .leading, endPoint: .trailing
            )
            .frame(width: geo.size.width * 0.6)
            .offset(x: isAnimating ? geo.size.width : -geo.size.width * 0.6)
            .animation(.linear(duration: 1.5).repeatForever(autoreverses: false), value: isAnimating)
            .onAppear { isAnimating = true }
        }
    }
}

// Skeleton card composition:
struct CardSkeleton: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            SkeletonView(variant: .rect, height: 180)
            SkeletonView(variant: .text, width: 200, height: 20)
            SkeletonView(variant: .text, height: 14)
            SkeletonView(variant: .text, width: 250, height: 14)
            HStack(spacing: 12) {
                SkeletonView(variant: .circle, height: 40)
                SkeletonView(variant: .text, width: 100, height: 14)
            }
        }
        .padding()
        .accessibilityLabel("Loading content")
        .accessibilityAddTraits(.updatesFrequently)
    }
}

// Wrapper that swaps skeleton for content:
struct SkeletonLoader<Content: View, Fallback: View>: View {
    let isLoaded: Bool
    let content: () -> Content
    let fallback: () -> Fallback

    var body: some View {
        Group {
            if isLoaded { content() }
            else { fallback().accessibilityHidden(true) }
        }
        .accessibilityElement(children: .contain)
    }
}
```

```kotlin
) {
    val shape = when (variant) {
        SkeletonVariant.Text -> RoundedCornerShape(4.dp)
        SkeletonVariant.Rect -> RoundedCornerShape(8.dp)
        SkeletonVariant.Circle -> CircleShape
    }

    val baseColor = Color(0xFF2A2A2E)
    val highlightColor = Color(0xFF3A3A3E)

    val brush = when (animate) {
        SkeletonAnimation.Shimmer -> {
            val transition = rememberInfiniteTransition(label = "shimmer")
            val translateX by transition.animateFloat(
                initialValue = -300f, targetValue = 300f,
                animationSpec = infiniteRepeatable(tween(1500, easing = LinearEasing)),
                label = "shimmer-x"
            )
            Brush.linearGradient(
                colors = listOf(baseColor, highlightColor, baseColor),
                start = Offset(translateX, 0f),
                end = Offset(translateX + 200f, 0f)
            )
        }
        SkeletonAnimation.Pulse -> {
            val transition = rememberInfiniteTransition(label = "pulse")
            val alpha by transition.animateFloat(
                initialValue = 1f, targetValue = 0.5f,
                animationSpec = infiniteRepeatable(tween(900), RepeatMode.Reverse),
                label = "pulse-alpha"
            )
            Brush.linearGradient(listOf(baseColor.copy(alpha = alpha), baseColor.copy(alpha = alpha)))
        }
        SkeletonAnimation.None -> Brush.linearGradient(listOf(baseColor, baseColor))
    }

    Box(
        modifier = modifier
            .then(if (width != Dp.Unspecified) Modifier.width(width) else Modifier.fillMaxWidth())
            .height(height)
            .clip(shape)
            .background(brush)
            .semantics { invisibleToUser() }
    )
}
```

```dart
class Skeleton extends StatefulWidget {
  final SkeletonVariant variant;
  final double? width;
  final double height;
  final SkeletonAnimation animate;

  const Skeleton({
    super.key,
    this.variant = SkeletonVariant.text,
    this.width,
    this.height = 14,
    this.animate = SkeletonAnimation.shimmer,
  });

  @override
  State<Skeleton> createState() => _SkeletonState();
}

class _SkeletonState extends State<Skeleton> with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1500),
    );
    if (widget.animate == SkeletonAnimation.shimmer) _controller.repeat();
    if (widget.animate == SkeletonAnimation.pulse) _controller.repeat(reverse: true);
  }

  @override
  void dispose() { _controller.dispose(); super.dispose(); }

  BorderRadius get _borderRadius {
    switch (widget.variant) {
      case SkeletonVariant.text: return BorderRadius.circular(4);
      case SkeletonVariant.rect: return BorderRadius.circular(8);
      case SkeletonVariant.circle: return BorderRadius.circular(widget.height / 2);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Semantics(
      excludeSemantics: true,
      child: AnimatedBuilder(
        animation: _controller,
        builder: (context, child) {
          return Container(
            width: widget.width ?? double.infinity,
            height: widget.height,
            decoration: BoxDecoration(
              borderRadius: _borderRadius,
              gradient: widget.animate == SkeletonAnimation.shimmer
                  ? LinearGradient(
                      begin: Alignment(-1 + 2 * _controller.value, 0),
                      end: Alignment(-1 + 2 * _controller.value + 0.6, 0),
                      colors: const [Color(0xFF2A2A2E), Color(0xFF3A3A3E), Color(0xFF2A2A2E)],
                    )
                  : null,
              color: widget.animate != SkeletonAnimation.shimmer
                  ? Color.lerp(const Color(0xFF2A2A2E), const Color(0xFF1A1A1E),
                      widget.animate == SkeletonAnimation.pulse ? _controller.value : 0)
                  : null,
            ),
          );
        },
      ),
    );
  }
}
```

* * *
## 10\. Accessibility
**`aria-hidden="true"`** on the skeleton shapes. They're decorative; screen readers shouldn't read "rectangle, rectangle, circle."

**`aria-busy="true"`** on the parent region. This tells AT the content isn't ready.

**When content loads:** flip `aria-busy="false"`. Optionally announce via a live region: "Content loaded."

**`prefers-reduced-motion`****\*\*\*\*:** stop the shimmer animation. The skeleton is still visible (gray shapes) so it still communicates "loading" without motion.

**Don't over-skeleton.** If the entire page is skeleton, a screen-reader user gets `aria-busy` on everything with no content to interact with. Consider a top-level loading announcement instead.

* * *
## 11\. Innovative / Emerging Ideas
*   **AI-predictive skeletons:** shapes generated from historical content patterns
*   **Streaming skeletons:** skeleton dissolves progressively as content streams in (Server Components)
*   **View Transition skeletons:** using the View Transitions API to morph skeleton → content
*   **Dark mode skeletons:** shimmer that shifts from dark-gray to slightly-lighter (not white highlight)

* * *
## 12\. Conversion / UX Killers
*   **Skeleton count mismatch:** showing 10 skeleton cards when the result is 2 items (or 0). Misleading.
*   **Skeleton that never resolves:** no timeout/error state. The skeleton sits forever.
*   **Layout shift on resolve:** skeleton dimensions don't match real content. CLS spike.
*   **Shimmer on everything:** 50 animated elements simultaneously is distracting and CPU-heavy.
*   **Skeleton for instant loads:** adds perceived delay to something that was already fast.

* * *
## 13\. Advanced Patterns
**Staggered reveal:** animate skeleton items out one by one as each data item arrives (streaming/suspense pattern).

**Content-aware sizing:** use the API response schema to generate skeleton shapes that match the expected content (short titles get narrow rects, long descriptions get more lines).

**Server-rendered skeleton:** include the skeleton in the initial HTML (SSR) so it appears instantly with zero JS, then hydrate to real content.

* * *
## 14\. Performance & Bundle Cost
*   **CSS-only shimmer** (pseudo-element + gradient + transform) is compositor-thread-only. Zero JS cost.
*   **Limit simultaneous animations.** 50 shimmering elements = 50 composited layers. Use `will-change: transform` sparingly and consider a single shimmer overlay on a parent instead.
*   **Reserve exact dimensions** so content swap doesn't trigger layout recalculation.

* * *
## 15\. Security
No security surface. Skeletons are purely visual, contain no data, and accept no input.

* * *
## 16\. Senior-Level Checklist
*   `aria-hidden="true"` on skeleton shapes
*   `aria-busy="true"` on the loading region
*   Skeleton dimensions match real content exactly (zero CLS)
*   `prefers-reduced-motion` stops shimmer animation
*   Timeout + error state (never show skeleton forever)
*   Shimmer uses compositor-only animation (transform)
*   Don't show skeleton for loads < 200ms
*   Skeleton count matches expected result count (or uses a safe default)

## 17\. Visual Styles
**Flat:** solid gray shapes, linear gradient shimmer. Clean and universal.
**Material:** slightly elevated skeleton cards with wave animation.
**Glassmorphism:** translucent shapes over a blurred background.
**Liquid Glass:** refractive skeleton shapes with subtle specular movement. Luxury loading.
**Neumorphism:** skeleton shapes are "pressed into" the soft surface.
**Skeuomorphism:** textured paper/card placeholders.
**Neo-Brutalism:** bold outlined shapes with no fill, hard edges.
**Claymorphism:** puffy rounded shapes with soft shadows.
**Aurora/Gradient:** shimmer is a multi-hue gradient sweep.
**Minimal/Swiss:** hairline-outlined boxes, no fill, no animation.
