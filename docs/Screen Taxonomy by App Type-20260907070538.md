# Screen Taxonomy by App Type

A screen taxonomy organized by the kind of app being built. Different app types share predictable screen families (list/detail/create, dashboards, checkout, chat, admin). Use this to identify which families your product needs, then pull specific screens into your Full Screen List.

* * *
## 1) Foundation Screen Families
These appear in almost every app type, even if the exact labels change:
*   **Authentication:** splash, welcome, sign up, log in, forgot/reset password, verification
*   **Onboarding:** intro tour, feature walkthrough, permission requests, first-time setup
*   **Navigation:** home, dashboard, search, browse, feed, menu, tabs, drawer
*   **Core content flow:** list, detail, create, edit, delete, preview
*   **Utility:** notifications, help, settings, profile, history, favorites, saved items
*   **System states:** loading, empty, error, offline, maintenance, success, confirmation

## 15) Building Your Own Taxonomy
Start with:
1. Universal screens
2. App-type-specific screens
3. Role-specific screens
4. Edge-case / system screens
5. Admin / support screens

That structure keeps the taxonomy usable for design, product planning, and database architecture instead of becoming a giant flat list.
