Audit checklist — what this playground proves

    

      
The accessible name never changes.
        Inspect the heading mid-pass: its name stays the real sentence. The scrambling node is
        aria-hidden; the truth node is clipped, not display:none.

      
Reduced motion is a branch.
        Tick the simulate switch: no animation is assigned, the scramble loop never starts, the
        scanline leaves the DOM, and the text renders final immediately.

      
No layout shift.
        The stage holds a reserved min-height, the noise node uses
        tabular-nums, and displacement is transform only.

      
The settle net holds.
        A timer at duration + 120ms force-lands the final state, so a throttled tab
        or a dropped animationend cannot strand the headline mid-corruption.

      
Text stays text.
        Select it, search it, zoom it, print it. The noise is written with
        textContent, never innerHTML.

      
Targets and focus.
        Every control here is a real button, select or
        input at a ≥44px target with a visible focus ring.
