What this playground proves

    

      
The accessible name never changes. Inspect the heading mid-pass: its name stays the real sentence. The scrambling node is aria-hidden; the truth node is clipped, not display:none.

      
Try the block pool. Switch the glyph pool to block glyphs and watch the tofu meter. If your display face is subset, those glyphs render as empty rectangles — indistinguishable from a broken font.

      
Try an emoji. Put Café ✨ built in the headline field. The grapheme meter stays green because cells come from Intl.Segmenter; text[i] would split the emoji into halves.

      
Reduced motion is a branch. Tick the switch: is-enhanced is never applied, the noise node is not rendered, no loop is scheduled, and the scanline leaves the DOM.

      
Width stays stable. tabular-nums plus a roughly monospaced pool keeps the measured width within 2px, so nothing below the headline hops.

      
Text stays text. Select it, search it, zoom it, print it. The noise is written with textContent, never innerHTML.
