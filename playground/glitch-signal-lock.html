What this playground proves

    

      
Push the radius past the cap. Drag blur above 6px and watch the unreadable-time meter climb. This is why the radius is typed as a literal union and clamped server-side — it is a legibility budget, not a taste knob.

      
It never parks blurred. The settle meter polls the computed filter after the pass. filter: none lives in the base rule, the reduced-motion branch and the print branch — never only in the keyframe's 100% stop.

      
The promoted layer is released. will-change: filter is bound to the glitching state and dropped on idle. Left on permanently it is a memory leak with good intentions.

      
The filter sits on a leaf. A non-none filter creates a stacking context and a containing block for fixed/absolute descendants, and blurs their focus rings. The meter scans the page for any filtered element containing sticky or fixed content.

      
Try the luma flavour. Contrast only, no blur: the text stays sharp and fully legible throughout. The safest option when there is real reading work nearby — and the one to watch for luminance flashing.

      
Decoration stays outside the filter. Turn on interlace: it is a sibling of the filtered node, not a child. Blur it and it turns to grey wash while obscuring the glyphs further.
